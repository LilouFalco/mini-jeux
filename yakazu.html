Comment on joue ? +

Chaque segment horizontal ou vertical de n cases, entre deux cases roses ou les bords, doit contenir les nombres de 1 à n, une seule fois chacun. Un segment de 3 cases contient donc 1, 2 et 3, dans n’importe quel ordre.

Une case isolée dans un sens ne crée pas de règle dans ce sens. Seul le segment qui la croise compte. Les chiffres foncés sont les indices de départ et ne peuvent pas être modifiés.

Touche une case puis un chiffre. Au clavier, utilise les flèches pour te déplacer, les chiffres pour jouer, Retour arrière pour effacer et N pour les notes. Pour le 10, utilise le pavé à l’écran ou la touche 0.

Les niveaux changent la taille et la proportion d’indices. La difficulté réelle varie d’une grille à l’autre.
