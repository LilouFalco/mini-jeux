Comment on joue ? +

Ouvre toutes les cases sans mine. Un chiffre indique combien de mines touchent la case, en comptant les diagonales. Une case vide ouvre ses voisines automatiquement.

Le premier clic est toujours sûr : la mine n’est placée qu’après lui, jamais autour de lui, pour ouvrir une zone.

Pour poser un cœur (drapeau) : appui long sur mobile, clic droit ou touche F sur ordinateur, ou active le Mode cœur puis touche. Touche une case ouverte dont le chiffre est égal au nombre de cœurs voisins pour ouvrir d’un coup toutes ses autres voisines (attention : un mauvais cœur fait perdre).

Au clavier : flèches pour bouger, Entrée ou espace pour ouvrir, F pour le cœur. Les grandes grilles se parcourent en les faisant glisser ; « Compact » rapetisse les cases.

Niveaux : Facile 9×9 (10 mines), Moyen 16×16 (40), Difficile 16×30 (99), Extrême 24×30 (160).
