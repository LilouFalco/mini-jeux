The server authenticates the departing actor, locks the room, stores a ten-minute private terminal receipt for former members, broadcasts a terminal invalidation on the existing private topic, then physically deletes the room with cascading state/members/receipts. No host transfer, old topic reuse, secret reuse, or reopening. Current safe default ends all group sessions on any departure too; future non-host group-continuation semantics are not implemented.

All new public RPCs accept a room ID only. No peer actor parameter. Only members or their own terminal receipt can receive status. Presence is advisory, never authorizes deletion or touches peer timestamps. Legacy board leave and non-board leave are overridden without modifying frozen 002. All four gameplay RPCs pass through their old implementations retained as private functions, whose execute ACLs are revoked. Legacy online_get_room delegates to lifecycle status. Independent review caught the initially unwrapped dedicated future-game RPCs; this candidate fixes them.

The server lease is 45 seconds since authenticated heartbeat, checked before renewing. Reconnection before expiry renews it, after expiry cannot resurrect it. Clients heartbeat every ten seconds including while hidden, subject to OS/browser suspension. Long mobile background suspension or a network partition can legitimately expire a session. Peers normally see expiration within 45 to 55 seconds. With every client closed, independent cron removes ghosts within 45 to 105 seconds under normal scheduler operation, not a hard real-time guarantee.

Cron uses the portable five-field minute schedule, not a version-sensitive seconds interval. The migration checks pg_available_extensions, attempts CREATE EXTENSION pg_cron, checks cron.schedule signature, schedules the named job, verifies active job creation, all in one transaction. Missing extension, preload, privileges, or scheduling failure aborts the entire installation. No claim that the hosted project's extension is enabled before the user's paste succeeds.
